## 1. 소개와 고지

JoyConMouse는 닌텐도 스위치용 Joy-Con 한 개를 Bluetooth로 PC에 연결해, 엄지 스틱으로 커서를 움직이고 버튼으로 클릭·드래그·스크롤하는 무료 오픈 소스 Windows 프로그램이다. 왼쪽(L)과 오른쪽(R) 조이콘을 모두 지원하며, 한 번에 한 대만 사용한다.

- **JoyConMouse는 닌텐도와 관계없는 독립 프로젝트다.** Nintendo Switch, Joy-Con은 Nintendo의 상표다.
- 자이로(기울기) 센서는 쓰지 않는다. 조이콘을 기울이거나 흔들어도 커서는 움직이지 않는다.

## 2. 준비물

- Windows 11 x64 PC (Bluetooth 지원)
- 스위치 1용 정품 Joy-Con (L) 또는 Joy-Con (R)
- JoyConMouse 배포 zip (`JoyConMouse-<버전>-win-x64.zip`). 압축을 풀 폴더만 있으면 되고, .NET 등 별도 설치는 필요 없다.

## 3. Bluetooth 페어링

1. Windows **설정 → Bluetooth 및 장치 → 장치 추가 → Bluetooth**를 연다. (앱의 **Bluetooth 설정** 버튼으로도 열 수 있다.)
2. 조이콘 레일(본체에 끼우는 면)에 있는 작은 **동기(Sync) 버튼**을 LED가 깜박일 때까지 길게 누른다.
3. 목록에 나타난 **Joy-Con (L)** 또는 **Joy-Con (R)**을 선택한다.
4. 한 번 페어링하면 다음부터는 조이콘의 아무 버튼이나 누르면 다시 연결된다.

## 4. 첫 실행과 장치 선택

1. 압축을 푼 폴더에서 `JoyConMouse.exe`를 실행한다.
   - "Windows의 PC 보호" (SmartScreen) 창이 뜨면 **추가 정보 → 실행**을 누른다. 첫 버전은 코드 서명이 없어서 나타나는 경고다.
2. 조이콘이 한 대만 연결되어 있으면 자동으로 선택된다. 두 대 이상이면 왼쪽 **연결된 조이콘** 목록에서 사용할 장치를 고른다.
3. 상태 표시줄이 **중립 대기 중 — 스틱과 버튼을 놓아 주세요**로 바뀌면 스틱과 버튼에서 손을 뗀다. 곧 **사용 중**이 되고 조작할 수 있다.
4. 다음 실행부터는 마지막으로 쓴 조이콘이 자동으로 선택된다.

조이콘은 **세로로** 쥔다. 스틱이 위쪽, 레일이 바깥쪽을 향하게 한다(왼쪽 조이콘은 레일이 오른쪽, 오른쪽 조이콘은 레일이 왼쪽).

### 연결 확인

설정 창의 **연결 확인** 탭에서 조이콘이 제대로 인식되는지 확인할 수 있다.

- 버튼을 하나씩 누르면 목록에 ✓ 표시가 붙고 왼쪽 그림에서도 같은 버튼이 켜진다.
- 스틱을 네 방향으로 끝까지 밀어 보면 방향마다 ✓ 표시가 붙는다. 손을 뗐을 때의 중앙 흔들림이 데드존보다 크면 경고가 나온다.
- 이 탭을 보는 동안에는 버튼을 눌러도 클릭·스크롤이 되지 않는다. 다른 탭으로 가거나 창을 닫으면 다시 마우스로 동작한다.
- 문제를 알릴 때는 **결과 복사**를 눌러 복사된 내용을 함께 보낸다.

## 5. 기본 버튼 배치

| 동작 | 왼쪽 조이콘 | 오른쪽 조이콘 |
|---|---|---|
| 커서 이동 | 스틱 | 스틱 |
| 왼쪽 클릭(누르고 있으면 드래그) | ZL | ZR |
| 오른쪽 클릭 | L | R |
| 위 / 아래 스크롤 | ↑ / ↓ | X / B |
| 왼쪽 / 오른쪽 스크롤 | ← / → | Y / A |
| 가운데 클릭 | 스틱 누르기 | 스틱 누르기 |
| 일시정지 / 재개 | − | + |
| 미지정 | 캡처, SL, SR | 홈, SL, SR |

- **드래그**: 클릭 버튼(ZL/ZR)을 누른 채 스틱을 움직인다.
- **더블클릭**: 클릭 버튼을 빠르게 두 번 누른다.
- **스크롤**: 짧게 누르면 한 칸, 길게 누르면 잠시 뒤부터 연속으로 스크롤된다. 같은 축의 반대 방향을 함께 누르면 멈춘다.
- **일시정지**: 일시정지 중에는 일시정지 버튼만 동작한다. 재개하면 스틱과 버튼을 놓은 뒤부터 다시 동작한다.

## 6. 감도·데드존·미세 이동·스크롤 설정

설정은 **왼쪽·오른쪽 조이콘별로 따로** 저장된다. 화면 위쪽 **편집할 쪽**에서 고른다(연결하지 않은 쪽도 미리 설정할 수 있다). 바꾼 값은 즉시 적용되고 자동 저장된다.

| 설정 | 의미 | 기본값 |
|---|---|---|
| 스틱 감도 | 스틱을 끝까지 밀었을 때의 최대 속도 | 1000 |
| 미세 이동 정도 | 클수록 스틱을 조금 기울였을 때 더 느리게 움직인다. 작은 버튼을 정확히 누르기 쉬워진다 | 2.0 |
| 데드존 | 스틱 중앙에서 이 범위 안의 움직임은 무시한다 | 15% |
| 스크롤 양 | 한 번에 스크롤하는 양(120이 휠 한 칸) | 120 |
| 반복 시작 지연 | 길게 눌렀을 때 연속 스크롤이 시작되기까지의 시간 | 300 ms |
| 반복 간격 | 연속 스크롤 간격. 작을수록 빠르다 | 100 ms |

커서의 실제 속도는 Windows **마우스 포인터 속도**와 **포인터 정확도 향상** 설정에 따라서도 달라진다.

**기본값 복원** 버튼은 편집 중인 쪽의 모든 설정을 기본값으로 되돌린다.

## 7. 버튼 재지정

1. **버튼 배치** 탭에서 물리 버튼마다 기능을 고른다(왼쪽 클릭, 오른쪽 클릭, 가운데 클릭, 네 방향 스크롤, 일시정지 토글, 없음).
2. 조이콘 버튼을 누르면 왼쪽 그림과 목록에서 해당 버튼이 강조되므로 어느 버튼인지 확인할 수 있다.
3. 한 기능을 여러 버튼에 지정할 수 있다. 예: 스크롤을 SL·SR에 지정하면 스틱을 움직이면서 스크롤하기 편하다.
4. **반대쪽 배치 미러로 가져오기**는 반대쪽 조이콘의 버튼 배치를 대칭 위치로 복사한다(ZL↔ZR, L↔R, ↑↔X, ↓↔B, ←↔Y, →↔A, −↔+, 캡처↔홈). 감도·스크롤 값은 복사하지 않는다.
5. 일시정지 토글 버튼을 하나도 지정하지 않으면, 일시정지 후에는 트레이 메뉴나 설정 창에서만 재개할 수 있다.

## 8. 트레이와 시작 프로그램

- 창의 닫기(X)를 누르면 프로그램은 종료되지 않고 작업 표시줄 오른쪽 **트레이**에서 계속 실행된다. 완전히 끄려면 트레이 아이콘 메뉴의 **종료**를 누른다.
- 트레이 아이콘 색: 초록 = 사용 중, 파랑 = 중립 대기, 노랑 = 일시정지, 회색 = 연결 없음, 빨강 = 오류.
- 트레이 메뉴: 일시정지/재개, 활성 조이콘 선택, 설정 열기, 시작 프로그램에 등록, 진단 정보 내보내기, 종료. 아이콘을 더블클릭하면 설정 창이 열린다.
- **시작 프로그램에 등록**을 켜면 Windows 로그인 시 트레이로 자동 시작한다. 프로그램 폴더를 옮겼으면 다시 켠다.
- 사용 중인 조이콘의 연결이 끊기거나 다시 연결되면 알림이 표시된다.
- JoyConMouse를 이미 실행 중일 때 다시 실행하면 기존 창이 앞으로 나온다.

## 9. 문제 해결

| 증상 | 해결 |
|---|---|
| 조이콘이 목록에 안 나타남 | Bluetooth 설정에서 연결 상태를 확인한다. 연결이 안 되면 장치를 제거하고 3장 순서로 다시 페어링한다. |
| 연결이 끊김 | 조이콘의 아무 버튼이나 누른다. 계속 끊기면 PC와 거리를 줄이고 다른 2.4GHz 기기와의 간섭을 확인한다. |
| 손을 뗐는데 커서가 혼자 움직임 | 감도 탭에서 **데드존**을 높인다. |
| 커서가 너무 빠름/느림 | **스틱 감도**와 **미세 이동 정도**를 조절한다. Windows 포인터 속도 설정도 영향을 준다. |
| 관리자 권한으로 실행된 프로그램 창에서 클릭이 안 됨 | Windows 보안 정책(UIPI)상 일반 권한 프로그램은 관리자 권한 창을 조작할 수 없다. 해당 창은 일반 마우스로 조작한다. |
| 마우스 버튼이 눌린 채로 남음 | 작업 관리자로 강제 종료한 경우 등에 생길 수 있다. 물리 마우스로 해당 버튼(왼쪽/오른쪽/가운데)을 한 번 클릭하면 풀린다. |
| Steam 실행 중 조작이 이상함 | Steam 입력이 조이콘을 함께 처리할 수 있다. Steam을 종료하거나 Steam 설정에서 Switch 컨트롤러 지원을 끄고 확인한다. |
| "조이콘 입력을 초기화하지 못했습니다" | 압축을 푼 폴더에 `SDL3.dll`이 있는지 확인한다. 배포 zip 전체를 다시 풀어 본다. |
| 절전·화면 잠금 후 동작 안 함 | 복귀 후 조이콘 버튼을 눌러 다시 연결하고, 스틱과 버튼을 놓으면 사용이 시작된다. |

## 10. 진단 정보 내보내기

문제를 알릴 때 트레이 메뉴 또는 설정 창 **진단 → 진단 정보 내보내기**를 누르면 바탕화면에 `JoyConMouse-진단-<날짜>.zip`이 만들어진다.

- 포함: 앱·Windows·SDL 버전, 설정 파일, 최근 로그, 내부 지연 통계, 연결된 조이콘의 좌우·이름·배터리 형태.
- 포함하지 않음: 조이콘 시리얼 번호, Bluetooth 주소, 장치 경로. 장치는 해시한 식별자로만 기록한다.
- 사용자가 버튼을 누를 때만 만들어지며 자동으로 전송되지 않는다.

설정 파일 위치: `%APPDATA%\JoyConMouse\settings.json` · 로그 위치: `%LOCALAPPDATA%\JoyConMouse\logs`
