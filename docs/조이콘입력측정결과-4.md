# 조이콘 입력 측정 결과

측정일 2026-11-13. 단독 조이콘(L/R)의 SDL 버튼·축 매핑을 실기기로 확인한 기록이다.

## 측정 환경

| 항목 | 값 |
|---|---|
| OS | Windows 11 Pro (10.0.26300) x64 |
| 입력 라이브러리 | SDL 3.4.20, HIDAPI 조이콘 드라이버 |
| 힌트 | `JOY_CONS=1`, `COMBINE_JOY_CONS=0`, `ALLOW_BACKGROUND_EVENTS=1`, `VERTICAL_JOY_CONS=1` |
| 장치 | 정품 Joy-Con (L) id …973b, Joy-Con (R) id …4fba (Bluetooth) |
| 측정 방법 | 앱 설정 창 **연결 확인** 탭 + **결과 복사**. 원문은 아래 부록 |
| Steam | 종료 상태 |

## 확정된 매핑 (세로 모드)

`src/JoyConMouse.Platform/Sdl/JoyConNormalizer.cs`의 세로 모드 표와 같다. SDL 소스로 정한 잠정값이 실측과 모두 일치했다.

| 왼쪽 물리 버튼 | SDL 게임패드 입력 | 오른쪽 물리 버튼 | SDL 게임패드 입력 |
|---|---|---|---|
| ZL | `LEFT_TRIGGER` 축 | ZR | `RIGHT_TRIGGER` 축 |
| L | `LeftShoulder` | R | `RightShoulder` |
| − | `Back` | + | `Start` |
| 캡처 | `Misc1` | 홈 | `Guide` |
| 스틱 누르기 | `LeftStick` | 스틱 누르기 | `RightStick` |
| ↑ ↓ ← → | `DpadUp/Down/Left/Right` | X / B / Y / A | `North` / `South` / `West` / `East` |
| SL | `LeftPaddle1` | SL | `RightPaddle2` |
| SR | `LeftPaddle2` | SR | `RightPaddle1` |

| 스틱 | SDL 축 | 방향 |
|---|---|---|
| 왼쪽 | `LEFTX`, `LEFTY` | 위 = Y 음수(−30354~−32768), 아래 = Y +32767, 왼쪽 = X −32768, 오른쪽 = X +32767 |
| 오른쪽 | `RIGHTX`, `RIGHTY` | 위 = Y −32768, 아래 = Y +32767, 왼쪽 = X −32768, 오른쪽 = X +32767 |

정규화 결과는 "세로 기준 X 오른쪽 +, Y 아래 +"를 만족하므로 축 회전이나 부호 반전 없이 그대로 쓴다. 정지 상태 값은 좌우 모두 정확히 0이다(SDL 보정 적용).

## 데드존 기본값 15%의 타당성

손을 뗐을 때 오른쪽은 0.000, 왼쪽도 데드존 미만이고 정지 값은 좌우 모두 정확히 0이다(SDL 보정 적용). 기본값 15%를 유지한다.

## 결론

측정 1~8 모두 통과했다. 세로 모드 힌트(`VERTICAL_JOY_CONS=1`) + 현재 정규화 표로 확정하며, 입력 방식 조정은 필요 없다.
