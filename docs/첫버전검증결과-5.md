# 첫 버전 검증 결과

작성 2026-11-13. JoyConMouse 0.1.0 첫 버전의 검증 기록이다.

## 검증 방식

사용자 결정(2026-11-13)으로 **실기기 검증은 핵심 항목만** 하고, 나머지는 **코드 리뷰로 대체**했다. 사용 중 발견되는 버그는 그때 수정한다. 아래 표의 "방식" 열이 각 항목을 어떻게 확인했는지 나타낸다.

- **실측**: 실제 조이콘·앱으로 확인
- **테스트**: Core 단위 테스트(19개 통과)로 확인
- **리뷰**: 코드 리뷰로 동작 경로를 확인(실기기 미검증)

## 코드 리뷰에서 찾아 고친 결함

| 결함 | 영향 | 수정 |
|---|---|---|
| Windows 로그오프·종료 시 창 닫기를 트레이 숨김으로 가로챔 | 종료 시 입력 해제·설정 저장이 보장되지 않음 | `Application.SessionEnding`에서 닫기 허용 + 입력 스레드 정지 + 설정 저장 |
| 장치 정보 재생성이 상태 발행 시각 기준 | 조이콘을 계속 쓰는 동안 배터리 표시가 갱신되지 않음 | 장치 정보 갱신 시각을 따로 두고 1초마다 다시 읽음 |
| 디바운스 저장과 종료 저장이 동시에 실행 가능 | 같은 임시 파일에 동시 쓰기 → 저장 실패 가능 | 쓰기 전용 잠금 추가 |

## 알려진 제한·후속 확인

- 연결 확인 탭을 연 채 다른 앱으로 전환하면 마우스 조작이 멈춘 상태가 유지된다(상태 표시줄·트레이에 "연결 확인 중" 표시). 창을 숨기거나 최소화하면 풀린다.
- 저장된 장치와 다른 조이콘만 연결되면 자동 선택하지 않고 선택을 요청한다(계획 T4 규칙 3).
- 위 표에서 "—"·"미실시"·"미측정" 항목은 사용 중 문제가 생기면 해당 태스크 절을 기준으로 확인한다.
